# Week 3 Summary: Regression Mastery

## What I Learned
- Linear regression predicts continuous numbers (y = mx + b)
- Loss functions: MSE, RMSE, MAE (MAE robust to outliers)
- R² score: 0.4–0.7 = moderate, 0.7–0.9 = good, >0.9 = excellent
- Train/Valid/Test split (60/20/20) prevents data leakage
- Feature scaling: StandardScaler (mean=0, std=1)
- Regularization: Ridge (L2) shrinks all, Lasso (L1) zeros some
- Bias-variance: underfitting vs overfitting tradeoff
- Pipeline bundles scaler + model into 1 object

## My Results
- Mini-Project #1: Test R² = 0.45 (moderate baseline)
- Best model: Linear Regression (Ridge/Lasso didn't help)
