## How they can work together

Embeddings can serve as a shared representation for multiple machine-learning tasks.

For example:

1. Convert abstracts into embeddings.
2. Use the embeddings to search for related abstracts.
3. Cluster the embeddings to discover broad research topics.
4. Train a classifier if labelled topic categories become available.

The embedding is not itself a class label or a cluster. It is a numerical representation that can support later tasks.

# Day 5 — Recall and ML Context

## Embeddings

An embedding is a numerical vector representation of an item. In this project, each neuroscience abstract is represented by a 384-dimensional vector generated by `all-MiniLM-L6-v2`.

Embeddings are useful because they allow text meaning to be compared mathematically. Related documents may have vectors pointing in similar directions even if they use different words.

## Pre-trained models

A pre-trained model has already learned general language patterns from a large text collection. It can convert new text into embeddings without training a new model from scratch on the small local corpus.

## Cosine similarity

Cosine similarity compares the directional alignment between two vectors. The search system compares one query embedding with every document embedding and uses the scores to rank the documents.

A cosine-similarity score is not a probability. It is a ranking measure whose interpretation depends on the model, corpus, and query.

## Semantic search versus keyword search

Keyword search looks for exact words or phrases. Semantic search compares the meaning represented by embeddings.

Semantic search can find relevant documents with different wording, but it may also return documents that are only broadly related. Keyword search is useful when exact terms matter, such as gene names, protein names, mutations, drugs, or methods.

## Limitations of the current system

- The corpus contains only 20 short teaching abstracts.
- The source URLs are placeholders rather than individual paper links.
- The corpus covers only selected neuroscience topics.
- The general-purpose model may not represent specialized biomedical language perfectly.
- Similarity scores are ranking values, not probabilities.
- The system always returns results, even when the query topic is absent.
- There is no labelled relevance dataset.
- There is no calibrated threshold for rejecting weak matches.
- Larger documents may require chunking.
- The model is loaded every time the script starts.
